# 교실 운동회

교실 TV에 운동장을 띄우고, 아이들이 태블릿으로 들어와 청팀·백팀으로 나뉘어 함께 뛰는 반 운동회예요.
운동장·체육관을 쓰기 힘든 날, 비 오는 날에 쓰려고 만들었어요. 가입이나 로그인은 없어요.

- 학생: https://seoyuha.github.io/sportsday/ → 방 번호 5자리 (또는 TV의 QR)
- TV(선생님): https://seoyuha.github.io/sportsday/?tv (선생님 비밀번호 필요)

## 종목 (13개)
큰 공 굴리기 · 장애물 달리기 · 박 터뜨리기 · 판 뒤집기 · 꼬리잡기 · 줄다리기 · 피구 · 무궁화 꽃이 피었습니다 · 단체 줄넘기 · 얼음땡 · 풍선 배구 · 깃발 뺏기 · 이어달리기

## 알아 두기
- TV와 태블릿은 인터넷으로 직접 연결(PeerJS)돼요. 학교 망에서 막히면 `index.html` 맨 위 `FIREBASE_CONFIG`에 Firebase 설정을 넣으면 Firebase로 중계해요.
- 반 기록은 TV PC 브라우저에만 저장돼요. 다른 PC로 옮길 때는 결과 화면의 '기록 내려받기' 파일을 반 고르기 화면에서 불러와요.
- 리허설: `?tv&bots=16&min=1` 로 열면 연습용 친구 16명이 들어와요.
